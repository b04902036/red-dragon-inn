## Primary mechanics/count source

- https://forums.giantitp.com/archive/index.php/t-211309.html

The RDI1 table lists mechanical effect categories and quantities for Deirdre, Fiona, Gerki and Zot.
The extracted rows sum to exactly 40 for each character. This package keeps those quantities but replaces card titles and full wording with original implementation labels and paraphrased summaries.

## Rules authority

Current RDI1 rules / searchable current-rule references:

- https://slugfestgames.com/wp-content/uploads/2021/10/RDI1RulesForWeb-12thEd-1.pdf
- https://www.64ouncegames.com/pages/the-red-dragon-inn
- https://slugfestgames.com/rulesfest-the-first-rule-of-sometimes/

Use current rules over old card wording when there is a conflict.

Key reconciliations:

- Sometimes legality is based on the immediate resolving effect, not future consequences.
- Gambling ante-causing cards are not treated as directly affecting Gold for generic Ignore-card triggers.
- response priority begins with the player who played/revealed the source.
- after a response resolves, players get a fresh response opportunity to the original source.
- Ignore and Negate are distinct.
- older copies of certain Wench-related cards follow current clarified restrictions.
- split/copy Drink effects create independent Drinks in the manner described by current rules.

## Confidence model

`MECHANICALLY_VERIFIED` means:

1. quantity/effect category is present in the complete RDI1 deck matrix; and
2. the implementation semantics are reconciled with current core rules where those rules clarify timing/interaction.

It does NOT mean this package reproduces the original printed title, flavor text, art, or exact rules prose.
