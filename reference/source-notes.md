# Research/source notes

## Current released scope

BoardGameGeek's `The Red Dragon Inn Character Compendium` v1.8 (July 9, 2026) states that it covers all **76 characters released so far** and completes the material through RDI 10, including Baelfire.

Official SlugFest Games rules index currently includes RDI 1–10 plus Allies and later variants.

These references are appropriate for:

- catalog completeness
- public product names
- public character names
- special-rule coverage planning
- rules architecture

They are not authorization to scrape and redistribute every proprietary card's complete text/art.

## Traditional Chinese terminology

A current Traditional Chinese edition is sold as `紅龍酒館`.
Public Traditional Chinese product/rule references use:

- 耐力值
- 酒精值
- 金幣
- 角色牌庫
- 飲料牌庫
  and describe the four core characters with localized names.

Taiwan community rule references consistently use:

- 棄牌抽牌階段
- 出牌行動階段
- 買酒/請客
- 喝酒
- 賭博
- 作弊
- 續杯
- 酒卡事件

The prompt pack chooses one canonical term per concept to prevent inconsistent UI translation.
