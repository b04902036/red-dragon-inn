For other characters:

- preserve canonical English name
- add a zh-TW translation/transliteration only with source/status metadata
- unverified transliterations must not be labeled official

## Translation consistency rules

- zh-TW files must use Traditional Chinese characters.
- Never mix `耐力值` and `毅力` for the same mechanic.
- Never mix `酒精值` and `醉酒值` for the same mechanic.
- Use `金幣`, not `金錢`, in stats.
- Use `暢飲區` consistently for the player's face-down Drink Me! area.
- Preserve English card/character canonical identity separately from localized display text.
