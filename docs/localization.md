# Presentation localization

The language selector is available on the landing page, lobby and table. English is the default; browsers using `zh-TW` start in Traditional Chinese. Explicit choices persist under `rdi:locale`. Each browser chooses independently. Changing language fetches public definitions through `GET /api/rooms/:id/presentation?locale=zh-TW` without reconnecting the WebSocket or sending commands.

`src/shared/ui-messages.ts` contains typed messages and interpolation parameters. Room notices and logs store message keys rather than translated strings, so already visible notices update with the selected language. `src/content/localization.ts` enforces the terminology in `reference/zh-TW-glossary.md`. Protocol names, effect operations, IDs, canonical definitions and deterministic replay do not change with locale.

Content packs accept translation records with entity, field, locale, text, source kind/reference and status. D1 migration 0007 stores these in `content_translations`, backfills previous metadata, and makes published records immutable. Translating published content creates a new edition; it never overwrites canonical English. Supported entities are products, characters, cards, rule modules, mechanic labels and choice options (`cardDefinitionId/optionId`). An unverified character translation displays its English name alongside it. `MANUAL_REVIEWED` describes a reviewed manual translation, not an official release name.

Production `zh-TW` presentation rejects missing, unreviewed, untranslated or inconsistent required fields. Explicit fixture mode can fall back to English. The original fixture edition remains unchanged; `content_sample_localized_v1` supplies reviewed original Traditional Chinese fixture text and is selected only by the fixture environment.

## Private translation workflow

Run `npm run content:translate:zh-TW` for usage. Supply `--input owned-pack.json --translations reviewed-zh-TW.json --version content_new --output content-private/imports/new-pack.json` to merge reviewed translations into a new ignored private pack. Without `--translations`, the tool creates a manual draft worksheet containing canonical English for review. A draft is not release-ready. The tool does not fetch or invent proprietary card text and never writes outside `content-private/imports`.

Run `npm run content:verify:zh-TW -- --input content-private/imports/new-pack.json` before importing/publishing that edition. The report lists missing fields, glossary violations, unreviewed text and duplicate or invalid records. Without `--input`, the verifier checks UI messages and the installed local production channel. If no production channel exists, it explicitly reports that absence; `content:verify:production` remains the release blocker.

## Visual verification

Run `npm run db:migrate`, `npm run db:seed`, then `npm run dev:fixture`. Open the displayed URL in a normal browser and an independent private window. Select 繁體中文 in one and English in the other, create a room, share its invitation, join and start. Confirm Chinese phase names, 耐力值/酒精值/金幣, 暢飲區, Chinese fixture card text, target/response dialogs and localized accessible labels. Change language mid-turn: the hand, selected cards, stats and active player should remain identical, with no reconnect flash. Complete a turn and refresh to confirm the preference persists. `.tools/step14-zh-TW.png` is generated by the full-turn browser test.
